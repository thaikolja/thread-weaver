# Composables

The Vue layer that holds the editor and talks to the browser. The notes below are the comments on the exports, so this page follows the code.

## `app/composables/useDisplayFade.ts`

### `useDisplayFade`

Brief opacity dip for the posts below the editor.

```ts
export function useDisplayFade()
```


## `app/composables/usePageMeta.ts`

### `usePageMeta`

Tab title and icons for the one-page tool.

Description, canonical, and Open Graph come from the SEO module.

```ts
export function usePageMeta(): void
```


## `app/composables/useThreadWeaver.ts`

### `useThreadWeaver`

One editor for the page.

Draft edits clear copy checkmarks, stop speech, and close the QR, because segment ids get reused after a fresh pack.

```ts
export function useThreadWeaver()
```


## `app/composables/useToolSchema.ts`

### `useToolSchema`

Structured data for the tool page.

WebSite, WebPage, and the author already come from the SEO module.

```ts
export function useToolSchema(): void
```


## `app/composables/useWeaverClipboard.ts`

### `useWeaverClipboard`

Copy buttons and their checkmarks.

- Parameter `posts`: The cards as they look right now.

```ts
export function useWeaverClipboard(posts: ComputedRef<readonly CompiledPost[]>)
```


## `app/composables/useWeaverContext.ts`

### `weaverKey`

One editor for the whole page.

```ts
export const weaverKey: InjectionKey<ReturnType<typeof useThreadWeaver>> = Symbol('weaver')
```

### `provideWeaver`

Create the editor and make it available under this page.

```ts
export function provideWeaver(): void
```

### `useWeaver`

The editor from the nearest provideWeaver().

```ts
export function useWeaver(): ReturnType<typeof useThreadWeaver>
```


## `app/composables/useWeaverDraft.ts`

### `useWeaverDraft`

The editable draft.

Every control, including the bridge box, goes through `commit`, so the cards update immediately.

- Parameter `onChange`: Runs after a real edit. Use it to clear copy ticks, stop speech, and close the QR.

```ts
export function useWeaverDraft(onChange: () => void)
```


## `app/composables/useWeaverPublish.ts`

### `useWeaverPublish`

Send, phone QR, and the markdown download.

They read the cards at the moment you click.

```ts
export function useWeaverPublish(options: {
  posts: ComputedRef<readonly CompiledPost[]>
  platform: ComputedRef<PlatformId>
})
```


## `app/composables/useWeaverSpeech.ts`

### `useWeaverSpeech`

The Listen button.

One card talks at a time. The voice is already on the machine, and it follows the words on the card.

Clicking the same card again stops it.

```ts
export function useWeaverSpeech()
```
