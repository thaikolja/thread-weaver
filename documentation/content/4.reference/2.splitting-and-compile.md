# Splitting and compile

Packing, markers, bridges, and the text tools. The notes below are the comments on the exports, so this page follows the code.

## `app/utils/weaver/split.ts`

### `splitSource`

Cut the source into chunks that fit the platform, minus room for the counter and the bridge.

A single word longer than that budget is kept whole. Empty input is one empty chunk.

```ts
export function splitSource(source: string, limit: number, bridge: string, keepBreaks: boolean): ThreadBlock[]
```


## `app/utils/weaver/compile.ts`

### `inlineJoiner`

The gap between text and marker when they sit on one line.

A bridge is wrapped in spaces. No bridge means one space.

```ts
export function inlineJoiner(bridge: string): string
```

### `compileText`

Stick the counter onto one chunk.

A bridge shows up right away for every placement, so typing "..." updates the card without touching the source or the placement menu.

`none` skips the counter, so the bridge has nothing to sit next to.

```ts
export function compileText(
  text: string,
  format: MarkerFormat,
  placement: MarkerPlacement,
  bridge: string,
  index: number,
  total: number
): string
```

### `polishSegment`

Optional cleanup before the counter is attached.

Capitalize lifts the first letter. Finish sentences adds … when the chunk has no ending mark.

```ts
export function polishSegment(text: string, capitalize: boolean, finishSentences: boolean): string
```

### `compileThread`

Turn every chunk into a post, in the current order.

```ts
export function compileThread(state: Pick<WeaverState, 'blocks' | 'marker' | 'placement' | 'bridge'> & Partial<Pick<WeaverState, 'capitalize' | 'finishSentences'>>): CompiledPost[]
```
